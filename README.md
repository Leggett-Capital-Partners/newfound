# NewFound Partners — Website

Static marketing site for **NewFound Partners**, a Houston-based value-add commercial real estate firm and a Leggett Capital Partners company.

Single-page site in the same design family as the Leggett Capital Partners and Cannon Field sites (navy / sky-blue / gold brand system).

## Structure

- `index.html` — page markup (nav, hero, stats, approach, portfolio, team, contact, footer)
- `styles.css` — brand system + layout
- `script.js` — nav, scroll reveals, count-up stats, portfolio asset-class filter
- `assets/` — logo, favicon, hero image, team photos

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Hosted via GitHub Pages from the `main` branch (root) in the `Leggett-Capital-Partners` org.
